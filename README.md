# Nikitha's Developer Portfolio

A personal portfolio website built with React and Vite to present my software engineering interests, selected projects, and professional links.

## Live Portfolio

[Visit the portfolio](https://nikitha-singh-portfolio.netlify.app/)

## Built With

- React
- Vite
- JavaScript
- CSS and HTML

## Run Locally

Requirements: Node.js and npm.

```bash
git clone https://github.com/Nikki03-tech/nikitha-portfolio.git
cd nikitha-portfolio
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Build the production site |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |

## Project Structure

- `src/` — application source code
- `public/` — static assets
- `index.html` — HTML entry point
- `vite.config.js` — Vite configuration

## Portfolio Goals

- Make selected projects easy to explore
- Provide quick access to source code and demos
- Help recruiters find my resume and professional links
- Present my learning journey in software engineering and Generative AI
